# Real-Time Collaborative Canvas — Client

The Refine + React client for a multi-user, real-time drawing canvas. Connects over
Socket.IO to a custom Strapi real-time provider.

**Live demo:** https://strapi-real-time-canvas.vercel.app
**Backend & full documentation:** [mnamvari/strapi-canvas-backend](https://github.com/mnamvari/strapi-canvas-backend)

## Stack

React 18 · TypeScript · Refine · Konva / react-konva · Tailwind · Vite · Socket.IO client

## Getting started

```bash
npm install
npm run dev   # http://localhost:5173
```

Configure the backend URL in `src/constants.ts`.
